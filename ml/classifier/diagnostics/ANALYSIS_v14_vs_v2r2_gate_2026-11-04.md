## 2. 가설 판별

### (a) 서빙 auto_crop 입력과 학습 bbox 크롭의 차이 → **v14 대 v2r2 격차의 원인은 아님**
- 근거:
  - 두 모델은 같은 서빙 경로를 쓴다. u2netp auto_crop의 bbox ±10% 크롭 입력이 같다.
  - 학습 이미지도 사실상 같다. v2r2 train 158,221장 중 92.9%(146,979장)가 v14 train에 있었다. 나머지는 사진 ID 그룹 재분할로 옮겨 온 장과 파손 크롭 184장이다.
  - 크롭 분포 차이가 있더라도 두 모델에 똑같이 작용한다.
- 남는 몫: gate 절대 수준(둘 다 CNN 단독 28~34/65)에는 영향이 있을 수 있다. 확인하려면 학습 크롭과 gate 서빙 크롭의 전경 비율을 u2netp로 비교해야 한다. gate 이미지에 전처리만 돌리면 되고, 이번 범위 밖이다.

### (b) 클래스 사전확률 변화(파손·상태 헤드 추가) → **데이터 쪽 근거 없음**
- 근거 1: metal 학습 데이터가 v14와 같다. v2의 metal 장은 모두 staging `metal`(6,295)·`metal_boost`(8,304) 폴더에서 왔고, v14가 쓴 것과 같은 폴더다. 재라벨로 metal에 들어온 장이 없다.
- 근거 2: 클래스 가중은 오히려 metal을 낮췄다. metal_can 0.52, metal_scrap 1.63이고, 표본 가중 평균은 0.58이다. 하나로 합쳤을 때는 0.63이다.
- 근거 3: 파손 오버샘플 ×20의 대상은 유리·형광등이다. 그런데 gate에서는 glass 확률이 오히려 0.106에서 0.057로 내려갔다. 사전확률 쏠림이었다면 glass가 올라야 한다.
- 정리: 출력 쪽에서 metal과 paper 쏠림은 실재한다. 하지만 학습 데이터의 비율이나 가중으로는 설명되지 않는다.

### (c) 백본 표현 변화 → **가장 유력**
- 근거 1: 임베딩이 더 촘촘해졌다. val 최근접 거리 p90(τ_soft)은 0.558에서 0.528로, p97.5(τ_hard)는 0.769에서 0.701로 줄었다.
- 근거 2: gate 사진이 v2r2에게 더 분포 안쪽으로 보인다. gate ood 중앙값을 τ_soft로 나눈 값이 0.87에서 0.82로 줄었다. 그래서 낯선 실사진에서도 확신이 높고, VLM 발동이 25회에서 11회로 줄었다.
- 표현이 바뀐 이유로 볼 수 있는 학습 쪽 차이(미검증):
  - 상태 헤드가 같은 pooled 특징을 공유한다. 상태 라벨은 train의 약 46%(70,714장)에 있고 가중은 0.25다.
  - v14는 셔플 샘플링, v2는 파손 ×20 WeightedRandomSampler(복원 추출)를 쓴다.
  - 세부 클래스가 27개로 늘었다(metal_can/scrap, food_inedible).

## 3. 다음 실험 제안 (실행 안 함, 리더 판정 대기)

1. (c)의 원인을 가리는 절제 실험: v2r2와 같은 설정에서 **STATE_W=0**(상태 헤드 학습 끔), 그리고 **샘플러를 셔플로** 바꾼다. 각각 5에폭이면 best 지점까지 간다.
   - 판정은 gate CNN 단독 확신 분포와 metal 확률 질량으로 본다. gate를 추가로 1회 쓰지 않으려면 val 기준 지표로 대신한다.
2. 학습 데이터가 아니라 출력 보정 쪽: 모델별 VLM 발동 문턱 보정. 서빙 기본값 변경이라 보류 항목이다.
3. (a)의 절대 수준 확인: gate와 학습 크롭의 전경 비율을 비교한다. 전처리만 돌리고 모델 평가는 없다.
