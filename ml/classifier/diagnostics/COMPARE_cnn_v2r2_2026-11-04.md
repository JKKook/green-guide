# CNN 분류 체계 v2 — 2회차(v2r2) vs 이전 모델 비교 (2026-11-04)

2회차는 v14와 달리 best를 val 재질 손실 최소 에폭으로 골랐고, 사진 ID 그룹 분할 v2.2를 써서 val/test 누설이 0이다. 파손 확정 크롭 184장을 넣었고, 상태 손실 가중은 0.25다.
holdout은 쓰지 않았다. 판정 기준은 gate 65 two_stage 재질 가드(대분류 ≥44/65, 전자제품 오탐 0/49, 재현 ≥12/16)다.

## ① 같은 출처 test — 새 분할 v2.2 (33,568장, 누설 0)

- 이 표의 전제: v14와 v2는 옛 분할로 학습했다. 그래서 새 test 안에는 옛 train에서 넘어온 사진 묶음이 있고, 그만큼 두 모델에 유리하다.
- 그래서 **주 지표는 '공정' 열**로 둔다. 사진 묶음이 옛 train에 한 장도 없던 27,821장이고, 네 모델 모두 처음 보는 사진이다.
- v2+T는 argmax가 v2와 같아서 test 정확도도 v2와 같다.

## 판정 의견 (GG_TRAIN)

- **가드 미달 — 채택하지 않는다.**
  - two_stage 대분류 38/65(기준 44)와 오탐 1/49(기준 0)가 기준에 못 미친다.
  - 재현 13/16은 통과다.
- **과적합(선정 시점)은 바로잡혔다.**
  - 틀린 장 중 확신 ≥0.95는 23장에서 7장으로 줄었다.
  - 그래도 틀린 장 평균 확신은 0.84로 v14의 0.68보다 높다. 그래서 VLM 발동이 11회로 v14의 25회에 못 미친다.
- **같은 출처 val/test와 실사진 사이의 차이가 주원인이다.**
  - test 공정 열에서는 v14와 0.4pp 차이인데, gate CNN 단독에서는 28 대 34다.
  - 선정 기준과 누설을 고쳐도 실사진 일반화는 오르지 않았다.
- **개선된 점:** CNN 단독 전자제품 오탐이 15에서 9로 줄었다. 다만 재현도 15에서 11로 같이 줄었다.
- **다음 회차 제안(실행 안 함):**
  - 실사진 분포의 학습 데이터를 늘린다. 배포 전이라 수집이 막혀 있으면 촬영 조건 증강이나 합성을 쓴다.
  - 또는 서빙 VLM 발동 문턱을 모델별로 보정한다. 서빙 기본값 변경이라 보류 항목이다.
