그린가이드는 회원 가입이나 계정이 없으며 이름·전화번호·기기 식별자를 수집하지 않습니다. 삭제 대상은 아래 두 가지입니다.

1. 기기 안에 저장된 데이터 — 앱에서 직접 삭제

  1. 분류 기록: 앱 「기록」 탭에서 개별 삭제하거나, 「설정 › 개발자 › 기록 전체 삭제」로 모두 지울 수 있습니다.
  2. 지역·주거 형태·수거 요일·알림 설정값: 「설정」에서 변경하거나 앱을 삭제하면 함께 삭제됩니다.

2. 서버에 업로드된 사진·분석 결과 — 이메일로 요청

  1. 업로드된 사진과 분석 결과는 재질 분석 목적 달성 후 30일 이내에 자동 파기됩니다. 결과 화면에서 「정확함」 또는 「피드백」을 제출한 사진은 분석 품질 개선 자료로 보유하며, 요청 시 삭제합니다.
  2. 삭제를 원하시면 whdrnrdldia@gmail.com 로 아래 정보를 보내주세요.
    • 삭제를 원하는 사진의 분석 일시(대략적인 날짜·시간) 또는 결과 화면에 표시된 업로드 ID
    • 「촬영 사진 AI 학습 활용」 동의를 철회하는 경우 그 뜻을 함께 적어주세요. 학습 데이터셋에서도 해당 사진을 제외합니다.
  3. 업로드에는 이용자를 식별하는 정보가 없으므로, 알려주신 일시·업로드 ID로 해당 기록을 찾아 삭제합니다. 접수 후 10일 이내에 처리 결과를 회신합니다.

3. 선택 동의 철회

  1. 수거일 알림: 「설정 › 알림」에서 끌 수 있습니다.
  2. 촬영 사진 AI 학습 활용: 「설정 › 정보 › AI 학습 활용 동의」 스위치를 끄면 이후 업로드부터 학습에 사용하지 않습니다. 이미 업로드된 사진의 제외는 위 2번 이메일로 요청해주세요.
