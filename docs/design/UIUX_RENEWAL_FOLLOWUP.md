## 후속작업

### 1. 수거일 알림 실제 발송 (우선순위 높음)
- 현재 상태: 알림 **저장·수정·토글·삭제 UI까지 완료** (`ReminderStore`), OS 알림은 발송되지 않음.
- 할 일: `flutter_local_notifications` 연동 — 요일 반복 스케줄링(당일/하루 전 구분), Android 13+ `POST_NOTIFICATIONS` 권한 요청, 알림 저장/토글/삭제 시 스케줄 동기화.
- "오늘의 팁 알림" 토글(설정)도 동일 — 하루 1회 로컬 알림.

### 2. 통합 검색 화면 (시안 7b) — ✅ 완료 (2026-08-20)
- `unified_search_screen.dart` 신설: 검색 하나로 품목 배출법·수거 일정·내 기록·가이드/설정 그룹 조회, 필터 칩(전체/품목/일정/기록/설정), 검색어 하이라이트, 빈 화면 예시 칩.
- 홈 검색창·"품목 배출법" 칩·하단바 검색 탭 모두 교체. 구 품목 검색 시트는 제거, 배출 기준 시트는 `widgets/criteria_sheet.dart` 로 이동.
- 남은 것: 빈 화면 고도화(최근 검색 저장), 결과 그룹 순서 조정 — 시안 다음 제안.

### 3. 수거 일정 실데이터 연동
- 현재 상태: `kDefaultWeekSchedule` 하드코딩 (월 종이·박스 / 화·금 플라스틱·비닐 / 일 일반 — 시안 4a 배치). 배출 시간 "18:00~24:00 · 문 앞"도 고정 카피.
- 할 일: 지자체(공공데이터) 수거일 데이터 연동 → 지역 설정과 결합해 요일·품목·시간 동적화. 출처 문구("○○ 폐기물 관리 조례 기준")를 실제 조례 명·개정일로.
- 시안의 다음 제안: 월간 캘린더 보기, 동네 변경 시트.

### 4. 스마트 촬영 플로우 (16a~16e) — ✅ 적용 (2026-08-21) · 남은 결정
- 적용: 진입 시트(16a) → 5초 카운트다운 캡처(16b, 카운트 종료 후 흔들림 안정 순간 촬영·최대 3초 대기) → 분석 중 다크 화면(16c, 업로드/전처리/AI 재질 분석/결과 생성 스텝퍼 + 분석 취소=다시 촬영) → 결과(16e, 분석된 재질·확신 pill·이렇게 버려요·정확함/수정·기록 자동 저장 캡션). 갤러리는 시스템 피커 → 확인 화면(16d 근사) → 동일 분석 단계.
- 결과 모달의 고급 기능(다중 물건 후보·탭 재분류·빗금 영역·CAM 설명·품질/불확실 배너)은 그대로 유지 — 시안 16e 표면 아래에 이어서 표시됨.
- "이렇게 버려요" 카드에 **지역 조례 규정 통합** (2026-08-21): 지역 설정 + 서버 `/region-info` 데이터가 있으면 "○○구 조례 기준" 배지 + 배출 방법/요일/시간/미수거일 행을 먼저, 구분선 아래 전국 공통 분리배출 요령. 데이터 없으면 전국 공통 + 안내 캡션(지역 미설정 / 데이터 준비 중). 별도 `_RegionCard` 는 제거.
  - 한계: 표준데이터는 재활용/음식물/일반 3분류 수준이라 **재질별 조례 세부 규정**은 아님. 진짜 재질별 조례 안내는 서버에 지자체×재질 규정 테이블 추가 필요 (백엔드 후속).
- 16f 피드백 시트 적용(2026-08-21): 칩 8종(플라스틱·페트병·비닐·캔·고철·유리병·종이·종이팩·일반쓰레기) + 직접 입력 → `corrected_label` 로 전송. 직접 입력값은 서버가 라벨 검증을 하면 거부될 수 있음 — 서버측 자유 라벨 수용 여부 확인 필요.
- 남은 결정: ① 16d 앨범 그리드를 앱 내 커스텀 그리드로 바꿀지(`photo_manager` 의존성 추가 필요) ② 시안 다음 제안 — AI 분석 실패/재시도 상태, 결과→기록 연결 ③ "닫아도 완료되면 알려드려요" 카피는 백그라운드 완료 알림이 없어 제외함.
- 제거: 구 스캔 탭(`scan_screen.dart`)·구 카메라 오버레이(`camera_overlay.dart`)·결과 하단 액션 바(다시 촬영/완료 → 헤더 X 와 분석 취소로 대체).

### 4-1. 온보딩 후속 (17 적용 후 남은 것)
- ✅ "우리 집 수거 요일" 반영 (2026-08-22): `effectiveWeekSchedule()` — 주택·빌라 + 요일 지정 시 해당 요일=재활용품(플라스틱·비닐) 배출, 나머지 배출 없음; 아파트/미지정은 동네 기본값. 홈 부제·주간 스트립·수거일 안내·통합 검색 일정·알림 품목이 모두 이 함수를 씀. 설정 > 내 동네 > "우리 집 수거 요일" 행(주택만)에서 변경. 한계: 사용자 지정은 재활용 한 종류만(종이·일반 요일 개별 지정은 미지원).
- ✅ 약관 UI·초안 (2026-08-22): `lib/data/legal_terms.dart`(문서 5종 — 이용약관·개인정보 수집이용·위치기반 서비스·수거일 알림(선택)·AI 학습 활용(선택)) + `terms_screen.dart`(목록·상세). 동의 시트 `>` 와 설정 > 정보 > 약관 및 정책에서 진입.
  - ⚠️ **법무 검토 필수** — 초안임. `[ ]` 플레이스홀더 확정: 운영자명/주소/문의처/개인정보 보호책임자/위치정보관리책임자/시행일, 사진 보유기간([30일]), 위치정보 확인자료 보관([6개월]).
  - 검토 포인트: ① 국외 이전 — 분석 API(Hugging Face)·저장소(Supabase) 리전이 국외면 개인정보 보호법상 국외 이전 고지/동의 요건 충족 필요(수탁자명·국가·항목·기간 명시) ② 위치기반서비스사업 — 위치정보법상 신고 대상 여부 확인(좌표를 서버 보관하지 않아도 서비스 제공 주체로서 요건 검토) ③ 만 14세 미만 아동 동의 절차(현재 문구만) ④ "AI 학습 활용" 철회 시 실제 데이터셋 삭제 프로세스 존재 여부 ⑤ 개인정보 처리방침 별도 문서(현재 동의서에 "처리방침을 따른다"고만 언급) ⑥ 알림 동의는 광고성 아님을 명시했으나 향후 마케팅 알림 추가 시 정보통신망법 별도 동의 필요.
- "배출 시간대" 행은 표시만(수정 불가).
- 시안 다음 제안: 지도를 행정구 단위 선택(리스트 병행) · 온보딩 완료 → 홈 첫 진입 코치마크.
- 테스트: 설정 > 버전 7탭 > 개발자 > "온보딩 다시 보기".

### 4-2. 미리뉴얼 화면 — 시안 부재
- **스플래시**는 캔버스에 시안 프레임이 없어 구버전 스타일 그대로임. 결과 모달의 고급 카드류(다중재질·reject·지역 카드)도 M3 기본 스타일.
- 관련: `kDisplayFontFamily`(PureunSup) 사용처가 `app_tooltip.dart`, `onboarding_screen.dart` 등에 남아 있음 — 해당 화면 리뉴얼 시 정리.

### 5. 다크 모드 시안 확정
- 시안은 라이트만 정의. 현재 다크는 `DsTokens`(design_tokens.dart)에서 기존 잉크 팔레트(#0F1419/#1A2027)에 맞춰 자체 매핑한 것.
- 할 일: 다크 시안이 나오면 `DsTokens` 값만 교체하면 전 화면 반영됨.

### 6. 소소한 결정 대기
- 기록 "모두 삭제": 시안에 없어 제거함 (개별 삭제는 카드 롱프레스). 복원 원하면 설정 > 정보 아래나 기록 헤더 메뉴로.
- 기록 카드 탭 동작: 현재 롱프레스 삭제만. 탭 → 결과 상세(결과 모달 재사용) 연결 검토.
- 알림은 요일당 1개로 제한(같은 요일 저장 시 대체) — 복수 허용할지 결정.
- Jua 폰트: `kDisplayFontFamily`가 PureunSup으로 유지되며 Jua 에셋은 미사용 상태 — 온보딩 등 정리 후 제거 검토.
