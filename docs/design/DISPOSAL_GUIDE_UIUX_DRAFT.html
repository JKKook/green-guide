배출 일정 & 대형폐기물 가이드 — 시안 방향

분류(무엇을) 다음 질문인 "언제 · 어떻게 버리나"에 답하는 두 기능의 UI/UX 방향. 기존 허브-앤-스포크 구조와 M3 디자인 시스템(brand #2E7D32 · Jua 디스플레이 · radius 12/16/22/28) 위에 새 화면 1개 + 기존 화면 확장 3곳으로 얹는 것을 제안한다.

설계 원칙 4가지

리서치에서 확인된 제약(아파트 일정은 공공데이터에 없음 · 대형폐기물 수수료는 228개 시군구 조례마다 다름)을 약점이 아니라 구조로 흡수한다.

① 조회가 아니라 "오늘"에 답한다

요일표를 보여주는 화면이 아니라 "오늘 재활용 버려도 되나?"에 즉답하는 카드가 1순위. 표는 그 뒤에 둔다.

반복 사용 동기 = 리텐션 훅
② 주거형태가 최상위 분기

단독·빌라 = 공공데이터 자동 세팅, 아파트 = 단지 일정 직접 입력. 같은 UI 틀에 데이터 소스만 다르게.

아파트 일정은 공공데이터에 없음
③ 대형폐기물은 판별 + 라우팅까지만

"이건 신고 대상"임을 알리고 관할 채널로 연결. 수수료 금액은 앱이 보장하지 않는다(조례별 상이).

수수료 DB 자체 구축 회피
④ 출처와 한계를 UI에 명시

"출처: 공공데이터포털 · 2일 전 기준" 표기를 기존 RegionCard 패턴대로 유지. 데이터 없는 지역은 빈 화면이 아니라 수동 입력으로 전환.

지자체별 등록 누락 대응

정보 구조 — 기존 그래프에 얹는 위치

새로 만드는 화면은 ScheduleScreen 하나다. 나머지는 온보딩·홈·ResultModal의 확장이라 내비게이션 그래프의 허브-앤-스포크 성격이 유지된다.

  1. 모드 배지를 AppBar에 상시 노출. 지금 보는 일정이 "공공데이터"인지 "내가 입력한 것"인지 화면 최상단에서 구분. 탭 전환이 아니라 주거형태 설정(설정 > 우리 동네)을 따라간다.

  3. 알림은 카드 1장, 토글 1개로 시작. 시간·품목별 세분화는 v2로. 전날 20시 로컬 알림(flutter_local_notifications)이면 서버 없이 완결.
  4. 아파트 모드는 같은 레이아웃의 편집 가능판. 행 구조를 재사용하되 "+ 품목 추가" 버튼과 자유 주기 입력(매월 둘째 주 등)을 허용. 공공데이터 미보유 시군구의 단독 거주자도 이 편집 UI로 폴백.
  5. "상시 배출 단지" 탈출구. 대단지 상시 분리수거장 거주자는 이 기능이 무의미 — 억지로 요일을 받지 말고 명시적으로 옵트아웃시켜 빈 알림을 만들지 않는다.

시안 D — ResultModal · 대형폐기물 분기

기존 결과 분기 4종(다중 재질 · 다중 물건 · 분류 불가 · 일반)에 다섯 번째 분기로 추가한다. 분류 라벨이 대형폐기물 품목군(가구 · 폐가전 등)이면 GuideCard 대신 이 카드가 뜬다.

다시 촬영
완료
  1. 판정 카드가 부정문으로 시작. "분리수거함에 버릴 수 없어요" — 대형폐기물의 핵심 정보는 재질이 아니라 '일반 경로 불가'라는 사실. 기존 PredictionCard 톤을 유지하되 GuideCard(배출함·방법) 대신 라우팅 카드로 교체. result_modal.dart 분기 5 — 라벨 → 대형폐기물 품목군 매핑 테이블(지역 무관, 로컬 상수)로 판정
  2. 과태료 배너는 warn 스타일 1장으로. 겁주기가 아니라 행동 근거 제시 — "수수료는 지역 조례마다 달라요" 문구로 앱이 금액을 말하지 않는 이유를 사용자 언어로 설명.
  3. 라우팅 버튼은 지역 인지형. 선택된 시군구의 신고 URL이 있으면 구청 직링크(primary), 없으면 여기로·빼기(outline)가 primary로 승격. 인터넷 신고 중단 지자체 대응. 시군구 → 신고 URL 매핑은 원격 구성(JSON)으로 배포해 앱 업데이트 없이 현행화
  4. 폐가전 무상수거는 항상 노출. 유일하게 전국 단일 제도라 확답 가능한 정보 — 소파 결과에서도 접이식으로 보여주면 "돈 내기 전에 확인"하는 세이프티넷이 된다. 폐가전 라벨이면 이 카드가 최상단으로 승격.

상황UI 반응원칙
공공데이터에 해당 시군구 없음 단독 모드여도 아파트형 수동 입력 UI로 폴백 + "이 지역은 아직 자동 안내가 준비 중이에요" 빈 화면 금지 — 항상 수동 입력 탈출구

공휴일 · 미수거일 홈 카드 헤드라인이 "오늘은 수거 없는 날이에요 (설 연휴)"로 교체 — 표준데이터 미수거일 필드 사용 판정문 우선 원칙의 연장
알림 권한 거부 토글 시도 시 설명 후 시스템 설정 유도, 거부 유지 시 토글 off 고정 + 홈 카드로 대체 안내 카메라 권한 화면과 동일한 복구 패턴
대형폐기물 판정 신뢰도 낮음 기존 "확실하지 않아요" 배너 재사용 + 일반 GuideCard와 대형폐기물 카드를 모두 표시하지 않고, "크기가 크다면 대형폐기물일 수 있어요" 소프트 카드로 강등 오판정 시 과태료 경고 남발 방지
