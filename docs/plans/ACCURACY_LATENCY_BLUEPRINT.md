### 반환 속도 — /predict-hier 실측

| 경로 | 로컬(M계열) | **운영(HF Spaces 무료 CPU)** |
|---|---|---|
| 장면 — 최적화 이전 | ~1.0s | ~15s |
| 장면 — B1+B2 (OCR 조건부+태그 TTA) | ~0.85s | ~4.6s |
| **장면 — B1+B2+B4 (DINO 제거, 2026-07-21)** | ~0.5s | **~1.6s** ✅ 예산 달성 (9.4×↓) |
| 탭 (+CLIP+CAM448+성분분리) | ~1.9s | 미측정 |

- B1: OCR 조건부(확신≥0.75 스킵). B2: EXIF 태그 TTA(태그有 2방향; tag=1 축소는
  -3건 회귀로 기각). **B4: DINOv2 제거** — 순수 홀드아웃 기여 0 실측(11/20 동률,
  이전 +2는 오염 표본 암기). env WASTE_API_DINO_W 로 재활성 가능.
- **B3(INT8)는 기각**: QUInt8/per-channel 3변형 모두 정확도 -1~-5 + Apple 로컬
  속도 역효과. (부산물: CAM einsum→1×1 conv 교체 — 향후 export 표준)
- 모든 판정은 순수 홀드아웃 20장 + 지연 3회 중앙값 실측 쌍 기준 (§1 원칙).

- 모델 추론(TTA 합)만 로컬 431ms — 나머지는 OCR(~0.4s)·게이트·세그먼트.
- 운영 15s 는 UX 실패 수준. 정확도를 위해 쌓은 직렬 스택(TTA×앙상블×OCR)이
  약한 CPU 에서 곱으로 터진 것.

## 1. 설계 원칙

1. **모든 정확도 개선은 순수 홀드아웃으로 판정** — 피드백은 절대 학습에 넣지 않는다.
   (표본 n<50 인 동안은 frozen + 육안 오답분석 병행, 단정 금지)
2. **지연 예산(운영 기준)**: 장면 p50 ≤ 2s / 탭 p50 ≤ 3s. 예산 초과 기능은
   조건부 실행 또는 비동기로 강등.
3. **정확도-속도 트레이드는 실측 쌍으로 결정** — "이 컴포넌트가 홀드아웃 +x건 / +y초"
   표가 없으면 기본값은 제거.
4. 게이트 개정: 대분류 recall 거부권은 **지지 ≥50 클래스**에만. 소표본(etc 31)은
   guidance-동일 이동(etc↔trash)을 회귀로 세지 않는다 (v8~v11 3연속 기각의 교훈).

## 2. 트랙 A — 정확도

| 단계 | 내용 | 기대/판정 |
|---|---|---|
| A1 | **피드백 축적 재개** (Supabase 쿼터 복구가 선결) + 앱 사용 | 홀드아웃 n 20→100+ |
| A2 | **Claude VLM 폴백**: reject/저확신(대분류<0.6)만 API 위임 | 어려운 케이스 즉시 구제 + 자동 라벨 축적. 학습 불요 |
| A3 | 서빙 융합 재스윕 (n≥50 후): TTA/DINO/OCR/CLIP 기여 재측정 | 컴포넌트별 (+건수, +지연) 표 확보 |
| A4 | v11 재판정 (n≥100 후) + 게이트 개정판 적용 | 외부 데이터 1.2만장 재활용 기회 |
| A5 | 해상도 320 (판정 가능해진 뒤 최후 레버) | 디테일 판별력, 학습 21h |

## 3. 트랙 B — 반환 속도 (운영 15s → 2s)

| 단계 | 내용 | 예상 절감(운영) | 정확도 영향 |
|---|---|---|---|
| B1 | **OCR 조건부**: 저확신·탭에서만 실행 (고확신 장면은 스킵) | -2~4s | 51장 실측서 플립 0건 — 저위험 |
| B2 | **TTA 축소**: EXIF 태그로 필요 방향만 (tag=1 이면 1회) | -50~65% 추론 | 태그 기반이라 무손실 근사 |
| B3 | **INT8 양자화**: R50·DINO ONNX (CLIP 에서 검증된 기법) | 추론 2~4× | cos≥0.94 수준 — 홀드아웃 확인 |
| B4 | **DINO 앙상블 재판정**: 순수 홀드아웃 기여 실측 후 유지/제거 | 제거 시 추론 -40% | A3 과 동일 실험 |
| B5 | **온디바이스 우선 하이브리드**: 폰 추론(수백 ms)을 1차 응답으로 즉시
     표시, 서버 융합(증거·지역)은 후속 보강 패치로 | 체감 15s→<1s | 1차 응답은 융합 없음 — UI 로 보강 표기 |
| B6 | (선택) HF Spaces 유료 CPU/GPU 업그레이드 | 2~5× | 비용 — 사용자 결정 |

권장 순서: **B1+B2 (즉시, 무손실) → B3 (반나절) → B5 (앱 UX 재설계 포함) → A2 → 나머지**.

## 4. 측정 프로토콜 (매 변경마다)

- 정확도: 순수 홀드아웃 전수 + frozen 게이트(개정판)
- 속도: 로컬·운영 각 3회 중앙값, 장면/탭 분리 기록
- 기록처: 이 문서 §0 표를 갱신 (수치의 단일 출처)
